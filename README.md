# Bread Will Walk — The Hunger Index

An illustrated, original reading of the bread transformation, reversed pursuit and sibling bond in Alex Boya’s film.

Open index.html in a browser. All six images, styles and interactions are embedded. No build, dependencies, analytics or server required.
